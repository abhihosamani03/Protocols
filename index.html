Protocol Reference & Performance Formulas

Key theoretical concepts and formulas behind sliding window flow control.

Protocol 1 One-Bit Sliding Window

Also known as Stop-and-Wait ARQ. The sender window size is strictly 1. The sender transmits a single frame and waits until the acknowledgement arrives before sending the next frame.

• Sender Window: 1
• Receiver Window: 1
• Efficiency: η ≈ 1 / (1 + 2a)
• where a = T_prop / T_trans
Protocol 2 Go-Back-N (GBN)

Allows the sender to transmit up to N frames without waiting for an ACK. The receiver accepts frames only in strictly consecutive order. If frame k is lost, receiver discards subsequent frames, forcing sender to retransmit all frames from k onwards (k → k+1 → ...) upon timeout.

• Sender Window: N
• Receiver Window: 1
• ACKs: Cumulative
• Retransmits: Entire window
Protocol 3 Selective Repeat (SR)

Avoids unnecessary retransmissions by having the receiver buffer out-of-order packets. When frame k is lost, only frame k is retransmitted. Individual timers are maintained for each unacknowledged packet.

• Sender Window: N
• Receiver Window: N
• ACKs: Individual / Selective
• Retransmits: Lost packet only

Performance Metrics Formulas

Throughput:

The rate of successfully delivered distinct frames per unit time (frames per second).

Throughput = Frames_Delivered / Total_Time

Efficiency (η):

Ratio of useful data transmission time to total transmission time, or useful frames to total transmitted frames.

η = (Unique_Delivered_Frames / Total_Frames_Sent) × 100%
